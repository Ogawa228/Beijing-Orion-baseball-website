注册球员管理

正式球员和试训球员统一在这里管理。试训队员的签到和手动积分会记在试训档案上，绑定或升级为正式球员时自动迁移。
个人标语、荣誉标签、头像、高光、绑定码、合并球员、积分明细都从球员卡进入，减少管理员在多个页面之间切换。

绑定码中心

为每个球员生成一个专属绑定码。球员注册账号后输入绑定码，系统自动将账号关联到球员真实姓名，并拉取照片与赛季数据。

系统设置

Demo 版数据存储在浏览器 localStorage 中。点击下方按钮可重置为初始状态。

添加球员

填写姓名 + 上传照片即可加入花名册

建议与赛季报名表姓名一致，便于自动匹配比赛数据
最多 14 个字，会作为金色 chip 显示在球员卡片名字下
每个荣誉用英文/中文逗号分隔，前 3 个会显示在卡片上

批量导入球员

两步：先粘贴名单，再批量上传照片，按姓名自动匹配

支持「姓名,号码,位置」三列，号码和位置可省略；使用中文或英文逗号皆可

新增比赛场次

选所属赛事 + 上传封面 + 上传 PDF / Excel。PDF 可直接解析；Excel 可按结构化工作簿一次导入多场比赛。

没有可选的赛事？先到"赛事"子 tab 创建一个

批量导入比赛

拖入或选择一个文件夹，里面放 GameChanger PDF + 同名封面图（可选）。
文件名规则：<客队>_vs_<主队>_<Mon>_<DD>_<YYYY>.pdf · 封面图取相同 base 名（name.pdf ↔ name.jpg）

创建新活动

活动会显示在首页"球队的日常与仪式"区。支持封面图、贴文正文和多张配图。

⚠ Demo 版无法直接抓取图片，请通过下方"上传配图"手动添加。正式版会接入云函数自动抓图。

建议 ≤ 30 字，会显示在首页活动卡片

合并球员数据

把“源球员”并入“目标球员”。源姓名会作为目标别名继续匹配原始比赛数据，源档案随后删除。

例如选 Andy：他的签到、积分调整、账号绑定等会迁走。
例如选 林立欣：之后 Andy 会作为林立欣的别名参与统计。
